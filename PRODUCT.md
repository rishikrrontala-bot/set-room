# Set Room
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Teachers running a projected SET game and classes competing for the fastest finish.
## Product Purpose
Recreate the user's classroom SET competition, remember completion times with class names and dates, and show the fastest class for the pizza prize.
## Operating Context
A teacher operates the shared screen while students identify sets. The user confirmed classic SET and a fixed number of sets to finish, and delegated additional competition improvements.
## Capabilities and Constraints
Daily common puzzle, class competition, server-saved results, daily and all-time rankings. Initial defaults: six sets for classic, three for sprint. Matched cards refill after each set. Repeated combinations are allowed if they appear again. Completion automatically saves class, date, and time. Practice does not affect rankings. School competitions use separate room codes. Original website unknown. No invented scores.
## Product Principles
- Make the board immediately available.
- Compare the same target and puzzle date fairly.
- Never lose a completed time silently.
- Credit Rishik Rontala visibly.

Manual Refresh cards deals a new solvable board without resetting the timer or found-set count. Ranked rounds permit up to 100 manual refreshes. Repeated combinations may be found again.
